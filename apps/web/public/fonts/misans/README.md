# MiSans VF

This directory contains the Simplified Chinese and Latin WOFF2 slices of
MiSans VF, self-hosted by Organize. The files were downloaded from Xiaomi's
official MiSans font service on 2026-09-20.

- Source: https://hyperos.mi.com/font/en/

- Embedded-font permission: https://hyperos.mi.com/font/en/faq/

MiSans remains the property of Xiaomi. Organize does not modify or redistribute
the font as a standalone product. The application includes it only as an
embedded interface font and keeps system font fallbacks for unsupported glyphs.
