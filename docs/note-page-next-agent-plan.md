## 2. 标题回车行为的完整定义

### 2.1 标题末尾按 Enter

1. 标题有内容、光标位于最后一个字符之后时：
   - 不修改标题文字。
   - 在正文最前方创建一个空段落块。
   - 焦点移动到该段落块。
2. 标题为空时按 Enter：
   - 同样进入正文的第一个可编辑块。
   - 不创建连续多个无意义的空块；若正文顶部已经是可直接进入的空段落，应复用它。
3. 正文已经有内容时：
   - 新块插在最前面，旧内容整体向后移动。
   - 禁止覆盖、合并或删除已有正文。

### 2.2 标题中间按 Enter

例如标题为 `今天的读书笔记`，光标位于 `今天的｜读书笔记`：

- 标题变为 `今天的`。
- 正文顶部新增普通段落 `读书笔记`。
- 原有正文排在新增段落之后。
- 光标进入新增段落，建议位于迁移文字的末尾。

还需覆盖以下边界：

- 标题中存在中文、英文、数字、Emoji、空格和长 URL。
- 用户选中一段标题文字后按 Enter：建议以当前选区起点作为拆分点，选中内容和其后的内容一并进入新块，不能静默丢字。
- 输入法正在组合文字时，`Enter` 可能只是确认候选词；必须检查 `isComposing` 或等价状态，不能误触发标题拆分。
- 快速连续按键和自动保存并发时，不得出现标题恢复旧值、正文重复插入或内容丢失。
- 拆分操作最好作为一个完整编辑动作，至少保证用户使用撤销时不会进入标题、正文互相不一致的中间状态。

### 2.3 不应混淆的正文标题块

正文内部的 H1/H2/H3 仍应遵循 TipTap/ProseMirror 的常规拆分规则：

- 在正文标题块末尾按 Enter，新建下一正文块。
- 在正文标题块中间按 Enter，前后文字拆成两个正文块。

这不是 T1/T2 的主要目标，但回归测试必须覆盖，避免修复页面标题时破坏正文标题块。

## 3. 超长标题要求

- 不设置前端 `maxLength`。
- 检查保存接口、共享类型、Supabase 字段类型和数据库约束，不能存在会截断标题的 `varchar(n)`、长度校验或转换逻辑。
- 页面标题输入控件需要支持自动换行和自动增高。可采用自动增高的 `textarea` 或语义等价实现，但数据仍保存为不含换行的单个标题字符串。
- 长标题不能横向撑破页面、覆盖按钮或造成正文宽度跳动。
- 至少验证：
  - 500 字中文标题；
  - 无空格的超长英文字符串；
  - 长 URL；
  - Emoji 和中英文混排；
  - 桌面端、窄屏和移动端；
  - 刷新后完整恢复。

“无限长”在产品语义上表示**不设置用户可见的字符上限**。仍需保留请求体大小、数据库容量和异常输入的基础安全保护，但不能把这些保护做成正常使用时可触达的标题长度限制。

## 4. 标题、正文等宽和“全宽”模式

### 4.1 当前需要核对的实现

- 笔记详情页入口：`apps/web/app/(main)/notes/[id]/page.tsx`。
- 当前页面外层存在固定的标准宽度容器；标题输入和 `TipTapEditor` 都在该页面中。
- 编辑器自身还有 `.organize-editor`、块操作手柄的预留区、内边距和负边距。不能只比较 DOM 外框，需要比较标题文字起点与正文文字起点、标题右边界与正文可编辑内容右边界。
- 不要先入为主认定是某一个 `max-width` 引起；用浏览器检查实际 DOM 和 computed styles 后再修改。

### 4.2 标准宽度

- 标题和正文共享同一个内容宽度变量或容器。
- 标题文字左边缘与正文块文字左边缘对齐。
- 标题和正文的有效右边缘一致。
- 六点手柄、加号等悬浮控件可位于内容区之外，但不能反向挤窄正文，不能让用户误以为标题比正文宽。

### 4.3 全宽模式

- 在笔记页面的更多菜单中提供“全宽”开关，与参考截图一致。
- 开启后同时扩展：
  - 页面标题；
  - TipTap 正文；
  - 表格、图片、代码块等正文块；
  - 与内容绑定的菜单、气泡工具条和区块手柄定位范围。
- 关闭后恢复标准宽度。
- 建议按**单篇笔记**持久化该设置，以符合 Notion 的页面级行为；刷新、重新登录和再次打开该笔记后保持状态。
- 若当前数据模型没有页面设置字段，先设计最小迁移和用户级 RLS，不能把设置混进 `notes.content` 的正文节点中。
- 窄屏下无论开关状态都必须保留安全边距，不出现横向滚动；桌面侧边栏展开/收起时应重新计算可用宽度。

## 10. 推荐默认决策

若用户没有补充说明，接手 Agent 可以按以下默认值执行：

1. 标题中间按 Enter 后，后半段作为**正文第一个普通段落**，原正文顺延。
2. 页面标题保持单一字符串；长标题通过视觉换行展示，Enter 专用于进入/拆分到正文。
