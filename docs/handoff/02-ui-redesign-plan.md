# Organize 界面改版执行计划

日期：2026-09-05；先读 `00-交接与执行顺序.md`。本方案以个人知识工作为默认场景，保留协作能力。是建议的第一版设计方向，不代表用户已经选定所有细节。所有路径相对仓库根目录。

## 1. 设计目标与第一版边界

方向名：安静的知识工作台。

关键词：暖白、炭灰、陶土橙、清晰文字、轻边界、紧凑导航、舒展正文。保留项目现有橙色识别，但降低大面积饱和度。应用像一张长期工作的书桌，不做营销落地页式大标题、渐变和大块装饰。

设计优先顺序：正文可读 → 路径清晰 → 保存状态可信 → 操作可发现 → 美观。视觉隐藏不等于移除功能。

第一版 D00–D01 只交：

1. 工作台桌面预览。
2. 笔记列表桌面预览。
3. 笔记详情桌面预览，含侧栏开关、辅助面板、更多菜单、保存异常。
4. 同一笔记详情移动预览。
5. 浅色/暗色切换，以及长标题、空状态样例。

不要求第一版做所有页面。不接真实后端，不拷贝 TipTap 保存逻辑，不修改仓库全局样式。演示输入只保存在预览内存，界面外清楚注明演示数据；任何“已保存”状态必须标明是演示状态，不能暗示真实落库。

用户选择方向后才进入 D02–D06 正式接入。第一版如果方向不对，只调整视觉和布局，工程可靠性修复继续独立推进。

- 最近笔记最多先展示 6 条，有“更多”；收藏/最近不能把页面树挤到看不到。
- 不在全局顶栏再重复放同一个搜索框和新建按钮。
- 新建打开现有创建选择器：保存链接/新笔记/新任务/速记；入口调整复用现有事件与 handler。

## 3. 布局系统

### 桌面与平板

| 宽度 | 侧栏 | 内容 | 辅助面板 |
|---|---|---|---|
| ≥1280px | 232px，允许折叠 | 正文优先，最大宽度见页面规格 | 笔记可打开 280px，默认关闭 |
| 1024–1279px | 默认 56px，可展开覆盖层 | 不同时永久显示三栏 | 右侧抽屉，不挤正文 |
| 768–1023px | 抽屉 | 单主内容区 | 抽屉/弹层 |
| <768px | 顶栏菜单抽屉 | 单栏，16px 边距 | 全宽 sheet |

按 CSS 实际可用内容宽度进一步收敛：即使窗口 ≥1280，正文可用宽不足 640px 时，辅助面板自动走 overlay，不能挤成细条。

主布局不要到处用固定 margin-left；统一 shell 变量控制 sidebar offset。笔记 tabs 36px，笔记工具行 48px；只有笔记区存在 tabs，不全站增加一排空白。

滚动所有权：正文使用现有主滚动容器；侧栏树可独立滚动；右侧面板可独立滚动。嵌套卡片不再造滚动区。修改主滚动容器前检查阅读进度、目录定位、sticky 和恢复滚动逻辑。

Z 层建议统一：正文 0、sticky 页头 20、导航 30、popover 50、抽屉 60、dialog 70、toast 80。复用 Radix Portal；不能凭一个极大 z-index 解决全部遮挡。

### 移动导航

首版正式接入保留现有“顶部菜单抽屉 + 底部搜索/新建”结构，减少重学成本；本轮不同时引入新的五项底部导航。

- 顶栏高 52px，左菜单/返回、中间短标题、右更多。路径进入更多或面包屑 sheet。
- 详情编辑聚焦/软键盘出现时收起底部悬浮按钮，失焦恢复；不能遮住光标、保存错误条或表格工具。
- safe-area 覆盖 iOS 底部和横屏；触控目标至少 44×44px。
- 不在移动端显示整条 Chrome 式 tabs，提供“已打开笔记 N”切换 sheet，保留关闭/切换能力。

## 4. 视觉规范

以下是目标色值。接入现有 Tailwind HSL 变量时统一转换；不要直接把 hex 填进 `hsl(var(--...))`。颜色必须经过实际文字对比度验证。

| Token 意图 | 浅色建议 | 暗色建议 | 用法 |
|---|---|---|---|
| app background | `#F7F6F2` | `#191A19` | 应用外层 |
| content surface | `#FFFFFF` | `#20211F` | 正文、弹层 |
| sidebar surface | `#F0EFEA` | `#1C1D1B` | 侧栏 |
| text primary | `#292C28` | `#E6E8E2` | 正文与标题 |
| text secondary | `#62685F` | `#A5ADA0` | 日期、提示 |
| subtle border | `#DDDFD7` | `#3A3E37` | 分隔 |
| selected neutral | `#E6E8DF` | `#30352D` | 导航与行选中 |
| brand | `#A4472B` | `#E39B7F` | 主动作、焦点、少量强调 |
| brand text on fill | `#FFFFFF` | `#211B17` | 主按钮文字 |
| error | `#B42318` | `#F6A99F` | 保存失败、危险 |
| success | `#356446` | `#9DCCA8` | 成功状态，配文字 |

非常重要：`hooks/use-theme-color.ts` 会写 inline CSS variables，覆盖 globals.css。不能只改 globals.css 就认为主题统一。保留已有 orange/blue/green/purple/pink 选择与 storage key；默认 orange 采用新色，其他色只影响品牌/焦点，导航选中保持中性。不要删除用户外观偏好。所有主题组合均检查文字对比度。

文字：沿用系统字体栈，中文 PingFang SC/Microsoft YaHei/Noto Sans CJK SC，英文 system-ui。第一版不下载远程字体。界面 14px，辅助 12px，页标题 24px/1.35，笔记标题桌面 34px/1.3、移动 28px/1.35；正文桌面 16px/1.85、移动 16px/1.8。保留用户衬线/等宽/小字设置；正常默认与已有 small_font 分开，不覆盖已存选择。

间距用 4/8/12/16/24/32/48；按钮 32–36px 高、输入 36px 高；移动输入 16px 字号。列表行 44–52px，文章行 88–104px。控件圆角 6–8px，浮层 10–12px；页面正文不套大圆角卡片。只给弹层轻阴影，列表靠间距和分隔线组织。

只用现有 Lucide 图标。避免每个模块不同彩色大图标；标签颜色保留用户语义，状态同时有文字/图标。动画 120–180ms，尊重 reduced-motion，不做背景装饰动画。

可访问性：普通文字目标对比度 ≥4.5:1，重要控件边界/焦点 ≥3:1；原生 Tab 顺序，Esc 关闭浮层并返回触发器；菜单用 Radix，不手写缺键盘行为的 div；保存变化用合适 live region，不每敲一个字播报。

## 5. 页面规格

### 5.1 工作台：继续做事，而非统计大屏

内容宽上限 1120px，桌面内边距 32px，移动 16px。

```text
工作台                                      今天 | 回顾 | 统计
9 月 5 日，星期六

[记录想法或粘贴链接…]                         [选择类型/创建]

继续处理（主列，约 2/3）                      最近笔记（辅列，约 1/3）
今天待办：最多 5 条                           3–5 条紧凑列表
□ 补齐阅读笔记          今天
□ 梳理下周计划          今天
查看全部待办

继续阅读：最多 3 条                           最近速记：最多 3 条
文章标题 / 来源 / 阅读进度                    短正文 / 时间
```

- 今天/回顾/统计复用 DashboardHub 的路由参数，不复制状态。
- 有待办就展示真实任务，没有则简短空态；不伪造“效率分”“知识资产”大数字。
- 采集框接原有 quick-add/collect 路径；粘贴链接的类型识别沿用原逻辑，未知输入默认速记并明确类型，不擅自替用户生成任务。
- <1024px 单列，次序为快速记录、今天待办、继续阅读、最近笔记、速记。
- 初次使用提供一个“保存第一篇文章”操作即可，不摆五个并列大 CTA。

### 5.2 笔记列表：标题和组织优先

上方一行“笔记 + 新建笔记”；下一行“最近/全部/图谱”，右侧搜索、排序、列表/卡片切换。现有排序、筛选功能须映射，不新增没有数据支持的筛选。

默认紧凑列表：图标 + 标题（主要）/父页面或来源（次要）/标签/最近编辑时间。小屏隐藏不必要列，标签最多两枚加 +N，长标题最多两行。桌面行高 52px 起。

保留已有卡片视图；无封面不生成占位大图；封面卡片默认不是唯一入口。页面树在全局笔记分组展开，列表页不再永久加一列树。

空库：“先写下一个想法”+新建；搜索无结果：“没有找到…”+清除筛选；加载失败：错误与重试，不显示成空库。

### 5.3 笔记详情：本轮设计重点

```text
全局侧栏       [阅读摘记 ×] [项目想法 ×] [+]                仅笔记 tabs
               笔记 / 阅读摘记          同步状态   分享  目录  更多
               ---------------------------------------------------
               [封面：仅有时显示，默认无封面]
               [页面图标]
               阅读如何变成自己的知识                       目录/评论等
               标签：阅读  方法     来源：某文章              辅助面板
               ---------------------------------------------------
               正文起点                                      默认关闭
               段落、标题、列表…

               子页面（有时）
               关联引用摘要（有时）
```

正文容器：标准模式最大 760px，左右自适应留白；full_width=true 沿用全宽，内部两侧至少 32px，移动 16px。数据库/宽表格在所属内容范围局部横滚，不让整页水平滚动。

默认选择标准宽度只应用于今后新建笔记的体验，若需要修改持久化默认值另列产品变更；改版不得批量覆盖已有 full_width、font_family、small_font、封面位置。

顶部工具行常驻：路径、真实保存摘要、分享（符合角色时）、目录、更多。历史/附件/评论/关联入口收进更多或辅助面板选择器；有未解决评论时可显示带数量的轻入口，不在所有页面永久排一整行小图标。

右侧辅助面板一次一种：目录 / 评论 / 关联 / 附件 / 历史。面板宽 280px，历史需要宽比较时使用现有预览对话框。选择器切换而不是同时打开多个面板；原有搜索、跳转、恢复、附件点击行为要保持。

原有正文底部关联摘要可保留一行计数与来源，点击打开关联面板，不重复渲染两套完整反链列表。加载不能宣称全量，R10 前对现有范围局限如实处理。

标题下属性：标签和来源优先，创建/编辑时间收进页面信息；图标/封面添加在 hover 与 focus-within 出现，触摸端更多菜单始终可访问，不能只靠 hover。

正文编辑：无常驻富文本大工具栏；选中文字 BubbleMenu；块手柄和 `/` 继续可用。空白正文一行轻提示“输入 / 插入内容”。不要改 TipTap DOM、拖拽坐标和事务来实现视觉。

斜杠菜单分组：

1. 常用：文本、标题、无序/有序列表、检查项、引用、图片、简单表格。
2. 组织：子页面、内部链接、折叠、标注、目录。
3. 高级：分栏、公式、Mermaid、嵌入、tabs、按钮、同步块、数据库。
4. 插件：按已启用插件显示。

默认常用优先，高级可展开；搜索跨所有已支持项。不可用的嵌套命令遵循 R06，不能设计层强行放开。AI 不是所有用户的首项；未配置时明确配置入口，不假装可以生成。

### 5.4 稍后读列表与文章详情（正式接入第二批）

列表页：标题/保存链接操作 → 未读/在读/已读 → 搜索、标签筛选、排序。默认标题为中心的行式布局，封面缩略图 96×64px；没有封面直接用文本布局。显示来源、预计阅读时长（已有数据时）、进度与状态。标签筛选继续同步 URL。

详情：文章正文标准 720–760px，来源/原文入口在标题下；高亮与笔记放可关闭右栏，小屏 sheet。转笔记、转任务沿用现有流程，不将整个网页编辑器混进阅读模式。正文颜色、行距统一但不破坏抓取内容、图片和高亮定位。

### 5.5 待办（正式接入第二批）

沿用侧栏清单和现有任务/日历/倒数日/经验/搜索子路由。顶部“任务、日历”为常用，倒数日/复盘/搜索可低强调，不删除入口；scope/list/q 跨视图保持。

任务行：勾选、标题、到期时间、必要标签、更多；复杂属性进详情。不要把所有日期/分类/优先级都做成彩色胶囊。完成反馈轻量，失败回滚依旧可见。

### 5.6 速记与辅助页

速记内容列最大 760px，顶部输入、下方日期流，标签为轻筛选；转笔记在项更多中，并保留易发现图标/标签。R11 完成前不得把“关联笔记已建立”画成真实状态。

收藏、垃圾箱、设置、插件复用统一页头、空态与列表密度。垃圾箱保留恢复和永久删除语义区分；设置页插件入口必须明显。图谱保留独立画布区域，不强迫放进正文窄列。

## 6. 必须设计的状态矩阵

| 状态 | 展示 | 操作 | 不允许 |
|---|---|---|---|
| 内容加载中 | 局部骨架 | 返回/导航可用 | 闪现空笔记并自动保存 |
| 同步完成 | 轻量“已同步” | 正常编辑 | 固定假成功 |
| 保存中 | 小 spinner+保存中 | 继续输入 | 锁住整篇笔记 |
| 仅本机保存 | 琥珀文字“已存本机，待同步” | 重试/导出 | 冒充云端完成 |
| 本机保存失败 | 持续错误条 | 导出当前内容 | 淡出后再找不到 |
| 版本冲突 | 持续提示+现有冲突框 | 比较/保留副本/选远端 | 默认覆盖远端 |
| 同步块失败 | 块内状态+页面摘要 | 重试 | 页头说全部同步 |
| 只读 | 只读标识 | 阅读/权限允许的复制导出 | 显示可写控件再报错 |
| 无权限/不存在 | 独立错误页 | 返回 | 泄露资源标题 |
| 离线不可读 | 清楚标注不可读 | 返回/联网重试 | 当成笔记不存在 |
| 长标题/大量标签 | 换行/折叠 | 可展开 | 撑出页面 |
| 空数据/无搜索结果/请求失败 | 三种独立状态 | 对应创建/清筛选/重试 | 全部显示“暂无数据” |

正式接入前若 R03/R05/R07 尚未提供可靠状态，不猜测它们；复用当前真实状态并记录待接入依赖。设计预览可模拟上述状态，但必须标明演示。

| 表格 | `table-direct-controls.tsx`、table extensions | 先验证坐标和横滚，不本轮重写 |

建议新增 `PageHeader`/`PageToolbar` 等前先查已有同名组件。共享模式真正重复两次后再提取；不要为了改版创建另一套 Button/Dialog 系统。

CSS 边界：新布局类放在 shell/page 区域，编辑排版限制 `.organize-editor`。不得写宽泛 `button`、`table`、`svg`、`p` 全局选择器覆盖嵌入内容和插件。清理旧规则需证明无使用，禁止追加一长串 !important。

## 8. 设计任务卡

### D00 内容与入口盘点（预览前置）

输入：本文件、现有 sidebar/main layout/notes pages/menus。

交付：把现有控件填入导航迁移表，记录所有角色入口；准备 4 组演示数据：普通笔记、长标题复杂笔记、空库、保存异常。只读检查，不写用户数据。

验收：历史、导出、附件、标签、页面设置、子页、任务、分享、搜索均有新位置；没有用“更多”掩盖完全没实现的入口。

### D01 独立第一版（用户先看这版）

在用户可访问的任务输出目录建独立预览，不放进正式路由。推荐沿用项目已有工具生成 HTML/CSS 或独立展示组件；不安装新的设计框架。

交付 4 个页面/视口与状态切换：工作台、笔记列表、笔记详情桌面、笔记详情移动。必要可操作行为：导航切换、侧栏展开、目录面板开关、更多菜单、保存状态切换、暗色切换。演示编辑可本地内存，不实现云端保存。

第一版必须达到：清楚展示正文与辅助功能的比例；不用真实后端即可打开；1366×900、1440×900、390×844 截图；至少一张暗色和一张错误状态。已画按钮要么有对应演示交互，要么标注为示意，不做假成功。

完成后先交用户评估，再安排接入；不要在同一轮顺手改业务仓库。修改建议按结构、密度、颜色、操作分别记录，避免一次全部推翻。

### D02 主题 token 与壳接入

前置：用户选定 D01 方向、工程 checkout 可独占。

范围：globals 的 token、Tailwind 映射、theme-color hook、主布局/侧栏/移动底栏。按导航迁移表保留旧入口替代路径。保留账户外观选择、主题切换和导航快捷键。

验收：浅暗/五种品牌偏好均不出现不可读；侧栏切换无正文跳位；抽屉可 Esc/点击遮罩关闭；移动按钮不挡编辑；旧 URL 正常；单一主滚动逻辑不破坏文章进度。

本卡不调整正文编辑器内部样式，不改保存函数。

### D03 工作台与笔记列表

前置：D02。

范围：dashboard 与 notes list 展示，复用实际 query/handlers。原页面筛选、排序、批量操作、创建、复制、打开 tabs、搜索全保留。

验收：加载、失败、空态、长标题和 100+ 条数据；点击列表打开正确笔记；工作台视图切换 URL 保持；不重复拉取整库只为重新排版。

### D04 笔记详情展示接入

前置：D02、R07–R09 完成且接口稳定；若尚未完成，继续设计预览，不复制原页逻辑。

范围：页头、tabs、属性行、正文宽度、辅助面板布局、菜单分组。沿用 session 与现有编辑器实例；面板开关不重建 editor、不丢选区。

验收：标题/图标/封面/字体设置正确；保存状态与实际一致；历史恢复/冲突流程完整；桌面与移动无功能丢失；full_width 已存偏好保持；表格和块手柄坐标正确；目录跳转没有被 sticky 顶栏挡住。

### D05 跨状态与响应式验收

前置：D03/D04。

视口：1440×900、1366×768、1024×768、768×1024、390×844、360×800；200% 浏览器缩放；浅暗；触摸；键盘。

逐项：保存错误不被 toast 遮挡；Popover 不出屏；抽屉焦点回归；移动键盘不挡最后一行；无页面水平滚动（内容内表格除外）；标签/长标题不撑宽；辅助面板关闭仍能发现入口；无隐藏不可达菜单。

运行原有类型、单测、lint/build/E2E；改菜单交互补少量行为回归，不写海量易碎截图断言。交付真实截图与失败记录，不只报告“响应式完成”。

### D06 次级页面统一

前置：第一版主页面验收通过。

顺序：稍后读列表→阅读详情→待办→速记→收藏/垃圾箱/设置/插件→图谱。每页独立小 PR；不同时修改文章抓取、高亮锚定、任务 recurrence 或图谱计算。

完成定义：视觉统一、实际入口映射完整、现有行为保持。每个页面只有外观改动时不新增无关业务测试。

## 9. 第一版评价标准

让用户用以下问题评价，不凭“像某个产品”判断：

1. 打开笔记第一眼看到正文和标题，还是看到很多按钮？
2. 是否能在两步内找到历史、导出、附件、目录和页面设置？
3. 是否能一眼区分已同步、本机暂存和保存失败？
4. 工作台是否能直接继续阅读或执行任务？
5. 390px 宽度下能否顺畅输入和切换笔记？
6. 连续读一页长文是否舒适，是否过宽或字号过小？
7. 已有功能是否仍可找到，是否只为了简洁而删除？

必须修复项：错误保存状态、缺入口、文字不可读、弹层挡输入、横向溢出、改版导致数据行为变化。偏好项：品牌橙深浅、边距松紧、侧栏宽度、默认列表密度。优先调偏好项，不轻易重新写业务。

## 10. 给执行者的禁止事项

- 不用大量渐变、玻璃模糊、超大圆角卡片、炫光和装饰性指标。
- 不自创“知识能量”“效率得分”等没有数据依据的模块。
- 不靠移除历史/冲突/导出/附件/分享来让笔记页变干净。
- 不从零实现富文本编辑器或替换现有 UI 库。
- 不改文档 schema、任务联动规则、保存 RPC、RLS 或匿名分享权限。
- 不自动清用户 localStorage、主题偏好或 full_width 设置。
- 不在设计阶段部署网站、发布桌面应用或连接用户生产数据。
- 不把预览完成说成业务改版完成；交付必须标清预览/已接入/待验证。
