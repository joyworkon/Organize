# 笔记智能物料整理

在笔记正文上方的「智能整理」区域拖入文件，或点「选择文件」。文件选定后立即识别，完成后把结果追加到当前笔记末尾；原有内容和编辑中的选区不会被替换。支持一次撤销本次插入。普通正文区域的拖拽、粘贴仍使用原有附件上传逻辑。

「选项 / 粘贴文字」可切换模式、粘贴文字或截图：

- **按内容整理**（默认）：按主题归纳、自动识别资料类型，生成标题、小节、要点、表格和资料中明确的待办。批量资料一起处理，保留来源对应关系。
- **提取并排版**：要求模型完整转录可辨认文字并恢复阅读顺序、层级和表格，不进行摘要；无法辨认的部分标记为 `[无法辨认]`。

分类与主题关键词展示在插入内容中，不会移动笔记或修改笔记的全局标签。AI 识别可能有误，插入结果可直接编辑并附带来源文件名提示。

## 配置

1. 在「插件」启用内置 **智能物料整理**（新插件遵循现有启动流程自动注册和激活，已有禁用状态会保留）。
2. 在「设置 → AI 服务」填写 OpenAI 兼容地址、密钥和模型。
3. 图片需要「文本 / 视觉模型」支持 Chat Completions 的 `image_url` 输入；录音另需转写模型。复用既有配置，不新增密钥存储或数据库迁移。

文件仅在用户主动选择或投放到整理区时发给所配置的服务商。原文件不自动上传为笔记附件；失败后保留文件列表，支持重试或「作为普通附件插入」。未配置模型、不支持视觉、输出格式错误等均明确报错，不生成假内容。演示模式明确提示不可调用真实 AI。

## 范围和上限

支持 PNG / JPEG / WebP / GIF；UTF-8 TXT / Markdown / CSV / JSON；MP3 / WAV / M4A / OGG / WebM 音频。不直接解析 PDF、Office 文档或视频，这些物料需先转为图片或文本，或走原有附件入口。

每批最多 6 个文件、合计 20MB，单图最多 8MB。纯文本文件最多 200KB，文字与音频转写合计最多 4 万字符。超过上限拒绝处理，不静默截断。每用户每分钟 5 次，复用支持 Postgres 的共享限流模块。

处理期间可继续编辑正文，结果插入时取最新文末位置。重复投放会被拦截；取消、离开笔记、编辑器销毁或失去编辑权限后不会插入迟到的结果。取消停止客户端等待，不保证已经发送给服务商的计算被取消。

## 扩展和安全边界

SDK 增加 `material-processor` 扩展与可选 `PluginDataAccess.organizeMaterials` 能力。插件通过宿主调用服务，不直接读取密钥。启用多个处理器时，投放区可选择使用哪个插件。

`POST /api/ai/materials` 校验会话、读取真实请求字节上限、校验文件类型和图片签名。AI 调用复用 `safeAIRequest` 的 SSRF 校验、连接钉扎、重定向检查和密钥脱敏。模型返回白名单结构，宿主与服务端均校验；只构建文本、标题、列表、待办、表格节点，不执行模型生成的 HTML 或接受任意编辑器节点。

测试覆盖输入与结果校验、多模态请求和音频转写、路由鉴权与限流、格式失败、脱敏、追加与撤销、等待期间编辑、重复投放、取消、卸载与只读切换、重试及附件回退。
