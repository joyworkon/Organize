# 构思画布：使用说明与验收记录

> 实现基于 [idea-canvas-plan.md](./idea-canvas-plan.md)（C01–C04 首版）。
> 分支 `feat/idea-canvas`；迁移 085–087；本文记录用法、A01–A17 验收结果与未验证事项。

## 使用说明

### 入口

- 桌面侧边栏「笔记」下方 **构思画布**（命令面板 `G C` 可直达；「快速新建 → 新建构思画布」一步建档）。
- `/canvas` 文档列表：新建 / 重命名 / 创建副本 / 删除（进垃圾箱，可恢复）。
- `/canvas/[id]` 无限画布工作区。

### 基本操作

| 操作 | 方式 |
| --- | --- |
| 新建页面 | 双击画布空白处（空白页面骨架：一个默认区块 + 标题块，出现在指针世界坐标，标题立即聚焦）；添加面板「页面」组「空白页面」「落地页骨架」（后者含头部/中部/底部三个区块，占位为提示文字）；空态也有同两个文字入口 |
| 页面名 / 区块名 | 选中页面后右侧属性栏改页面名；区块名点击即改（区块左上角标签，输入框内按键不触发画布快捷键）；选中区块时属性栏可改区块名/背景/内边距/行间距/装饰边框 |
| 添加内容（B2） | 左侧添加面板「添加」组六项：标题、正文、图片、列表、分隔线、行动按钮。落点由统一插入规则解析（见下「插入规则」），面板顶部实时提示「添加到：{区块名}」 |
| 插入规则（B2） | 优先级：① 明确点击某个「＋」→ 该位置；② 选中块 → 同列该块之后；③ 选中区块 → 区块末尾追加一行；④ 选中页面 → 最后一个区块；⑤ 无选中 → 最近使用过的页面+区块；⑥ 完全空白 → 自动创建页面再插入。**默认不创建脱离页面的自由内容**；「自由放置」折叠区（自由文本/自由图片，标注「自由定位，不随页面排版」）是显式次级入口 |
| 三类加号（B2） | 块下＋＝同列下方加内容块（半透明预览）；行边缘左右＋＝给当前行加列；区块之间（Region 间隙悬停）＋＝在两区块间插入新区块；行右下横条＋＝添加通栏（同 Enter）。悬停预览按场景几何实时计算，不写入文档 |
| 结构 / 模板 | 添加面板「结构」（页面→区块树：点击选中并平移定位、双击/铅笔改名、上移/下移/复制/删除）与「模板」（空白结构 / 图文介绍 / 三列卖点 / 行动区）折叠分组；模板插入当前选中页面（无选中 → 最近页面 → 自动建页） |
| 区块操作 | 结构分组改名/上移/下移/复制/删除；点区块空白选中；Delete 键删除选中区块（版面保底保留一个可输入空块） |
| 输入 | 单击选中、双击进入编辑；`Enter` 在当前**区块**末尾新增通栏行（不跨出当前区块）；`Shift+Enter` 模块内换行；中文输入法候选确认（isComposing）不会误建块 |
| 新块类型（B2） | **分隔线**：token 色细线，属性栏仅对齐/删除；**行动按钮**：纯链接（仅 http/https，编辑态点击=选中不跳转，预览态才是可点链接，非法链接渲染禁用态）；**列表**：文本块角色，逐行项目符号，Enter 语义与正文一致 |
| 图片（B2） | 三入口统一流程：添加面板「图片」按钮、拖入画布（指针命中列/区块）、粘贴（指针落点）。上传中就地插入占位（转圈），成功后原地更新、失败后原地重试/重选；上传期间改选区不影响在途目标；占位被删/撤销后迟到的完成**不会插回**——转为「待重新放置」自由图片 + 提示，可属性栏「移入区块…」归位。多图按选择顺序同列追加 |
| 图片属性（B2） | 容器比例（原始/1:1/4:3/16:9，版面块同样锁高）、定比例时显示完整显示/铺满裁切（auto 时隐藏，避免「看起来没作用」）、替换图片（保留位置与全部设置，失败保留旧图）、说明文字（alt，持久化） |
| 左右加号 | 悬停模块时出现在所属列左右边缘，点击给当前行加一列（所有列重新分配宽度，版面总宽不变）；放不下最小列宽（120）时禁用并提示加宽版面 |
| 模块底部加号 | 仅在本列、当前块下方插入新块（与通栏是不同按钮、不同预览） |
| 添加通栏 | 行右下「横条 +」按钮，效果与 Enter 相同 |
| 块级操作 | 右侧属性栏：复制 / 上移 / 下移（列内交换） |
| 所在行（B2） | 选中任意块时属性栏「所在行」组：加列/减列（仅空列）、列宽（等分/1:2/2:1/智能比例/两列自定义滑杆，连续拖动合并一个撤销事务）、行内间距滑杆、垂直对齐（拉伸/顶/中/底——非拉伸时块保持自然高按列对齐） |
| 调整列宽 | 拖动列间分隔线（整次拖动一个撤销事务；之后该行为手动比例，可属性栏恢复「等分 / 智能比例」） |
| 版面移动 / 改宽 | 悬停版面顶部操作条拖动移动；右缘拖动改宽（智能比例行随后自动重算）；页面属性：名称/宽度/内边距/背景/圆角 |
| 自由容器 | 「自由放置」折叠区「自由文本 / 自由图片」；拖动移动、右下角改宽、属性栏调层级；属性栏「移入区块…」把自由对象迁入指定页面→区块（可撤销）；`Enter` 只换行；选中显示「自由定位」徽标，不参与自动排版 |
| 样式 | 右侧属性栏：角色（标题/正文/列表）、字号档、加粗、文字色、对齐、背景、圆角；版面：页面名/宽度/背景/圆角 |
| 键盘 | `⌘Z/⇧⌘Z` 全局撤销重做：画布块内输入由画布统一接管；页面名、属性栏等普通输入框走原生编辑，不被抢；`Esc` 退编辑/清选区（弹层打开时让位给弹层关闭）；输入框内 Delete/空格/方向键不触发画布操作 |
| 缩放 / 平移 | Ctrl/⌘+滚轮围绕指针缩放（10%–400%）；滚轮/触控板平移；空格或中键拖拽平移；右下角 −/+/100%/适合全部；添加/插入时若目标不在可视区会自动平移带入（已在视口则不跳动） |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z`（含文本输入，连续输入合并为一个事务；IME 一次提交一个事务） |
| 预览 | 顶栏眼睛图标或 `Esc` 退出；隐藏全部编辑控件；行动按钮在预览态渲染为可点链接 |
| 保存 | 停止编辑约 800ms 自动保存（串行 + revision CAS）；状态显示「保存中 / 已保存 / 仅保存在本机 / 保存失败 / 存在冲突」；mock 下显示「已保存（演示模式，仅本机）」 |
| 冲突 | 保存被拒（他人/他标签页已更新）时暂停自动写回，提供「查看云端版本 / 将本地内容另存为副本 / 暂不处理」 |
| 删除 / 恢复 | 版面操作条删除版面、属性栏删块/容器；文档删除进垃圾箱，可恢复、可彻底删除 |

### 手机端

从侧栏抽屉进入；列表为标准页面；详情**只读预览**（返回、缩放可用），顶部提示编辑请在桌面进行；底栏仍为五个入口，不新增。添加面板与加号仅编辑态出现，只读全隐藏。

### 属性栏对照表（B2）

| 选中对象 | 属性 |
| --- | --- |
| 无 | 简短操作指引（无占位控件） |
| 页面 | 名称、宽度、内边距、背景、圆角、删除页面 |
| 区块 | 名称、背景、内边距、行间距、装饰边框开关（上移/下移/复制/删除在「结构」分组） |
| 任意模块 | 背景、圆角、所在行（加列/减列、列宽等分/1:2/2:1/智能比例/两列滑杆、行内间距、垂直对齐）、复制/上移/下移、删除 |
| 文本（标题/正文/列表） | 角色（切角色重置字号字重）、字号档、对齐、加粗、文字色 |
| 图片 | 容器比例（原始/1:1/4:3/16:9）、定比例时显示完整显示/铺满裁切、替换图片、说明文字（alt） |
| 分隔线 | 对齐（左/中/右）、删除 |
| 行动按钮 | 文案、链接（仅 http/https，非法/为空渲染禁用态）、对齐、主要/次要样式 |
| 自由文本 | 角色（标题/正文）、字号档、对齐、加粗、文字色、层级、圆角、移入区块…、删除 |
| 自由图片 | 完整显示/铺满裁切、容器比例、层级、圆角、移入区块…、删除 |

所有属性遵循「修改 → 画面更新 → 约 800ms 自动保存 → 刷新还原 → ⌘Z 可撤销」全链；滑杆连续拖动经
coalesce 合并为一个撤销事务；点击属性栏不会取消画布选区（输入框按键不触发画布快捷键）。

### 主题与字体接入（PR #319 视觉系统）

- 画布根显式声明与全局一致的字体栈：`"MiSans VF", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
- MiSans 自托管加载完成（`FontReadyBridge` 派发 `organize:fonts-ready`、置 `data-fonts-ready`）后，画布清空文本测量缓存并整体重算场景（文字、节点盒与后续锚点类几何都由场景派生）；初始化时若标记已为 `true` 立即重测一次，避免字体前后布局偏移。
- 颜色全部使用主题令牌（`--background/--foreground/--card/--primary/--primary-foreground/--primary-text/--muted/--muted-foreground/--accent/--border`），未另建色彩体系；画布色板（--cv-*）仅承载用户给内容挑的语义色，明暗各自解析。
- 圆角一律取 `--radius-xs…2xl` 变量，并在支持时对画布表面（版面、属性栏、工具条、缩放控件、横幅、自由容器、模块、列表卡）启用 `corner-shape: squircle`。
- 小号提示文字（占位符等）使用主题校准过的完整 `--muted-foreground`，浅/暗色均满足 WCAG AA。

## 数据与备份

- 独立 `canvas_documents` 表（`content` 为结构 JSON，`schemaVersion=2` + `revision` 并发修订）。
- **数据模型（阶段 B1 起）**：Board(**页面**) → **Region(区块)** → Section(**行**) → Column → Block。
  - v1 的 Section 实际承担行布局，v2 字段结构不变、语义为「区块内的行」，代码内类型名保留 `CanvasSection`；
  - Region：`{ id, name(≤100), style?: { background, padding(缺省0), rowGap(缺省继承版面gap), border }, sections }`，每页面上限 20 个；
  - 版面可带可选 `name`（页面名）；保存永远写 v2。
- **块类型（阶段 B2 起）**：`text`（角色 `title|body|list`，list = 逐行项目符号）、`image`（`asset/fit/ratio/alt`，ratio 容器比例版面块与自由图片同语义）、`divider`（分隔线，仅 align 样式）、`button`（`label/href/align/variant`，href 仅 http(s)）。新类型只出现在 v2 文档；未知类型保留占位并阻止保存的语义不变。
- **迁移语义**：`migrateCanvasDocV1toV2` 纯函数——每个 board 的原 sections 按原顺序包进一个默认 Region（id 由 `r-<boardId>` 确定性派生，name「内容」，style 留空）；全部原 ID/样式/内容逐字段不变，freeItems 原样；幂等（v2 原样返回）。读取侧统一入口 `ensureCanvasDocV2`：v1 自动迁移、v2 直返、未知更高版本原样保留（由校验拒绝保存）。加载路径（repository get、草稿恢复、mock shim 读）都走它；服务端/mock 校验收到 v1 时先迁移再校验、以 v2 落库（防旧客户端写入丢层级）。备份 v6 恢复出的 v1 content 读取时自动迁移、下次保存写 v2（有单测断言）。
- 全局设置页备份导出/恢复自动包含画布（格式 v6，兼容导入 v2–v5 旧备份）；附件打包/恢复会收集并重绑画布内的 `/storage/` 图片引用。
- mock 模式：文档存内存（刷新即失），草稿与本机图片存 IndexedDB（按账号隔离）；上传走本机适配器（`mock-image:` 引用，刷新后由草稿/本机重建预览）。

## 未验证事项（环境限制，需真实环境补验）

1. **数据库层完全未在真实 Supabase 验证**（本机无 Docker）：迁移 085（表/RLS/GRANT/触发器/`canvas_document_patch` CAS RPC）、086（垃圾箱 RPC 接入）、087（备份恢复链）均按既有迁移模式（055/073/060/075）编写且 mock 对齐契约，但 RLS 用户隔离、CAS 原子性、RPC 权限口径需 `supabase start && supabase migration up` 后补验（A12/A13 的真实后端部分）。
2. 真实硬件中文输入法（搜狗/系统 IME）的 Enter 手感与候选确认（A06）。
3. 真实图片上传（/api/upload → images bucket）后的智能比例重排全链（A07）与备份附件往返（A14）。
4. 真实双标签/双账号并发冲突（A12）与迟到保存竞争（A13）。
5. 性能目标（5 版面 200 模块 P95<100ms）未做基准测量；当前实现为全量重渲染 + 测量缓存，未做虚拟化。
