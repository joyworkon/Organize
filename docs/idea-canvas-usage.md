# 构思画布：使用说明与验收记录

> 实现基于 [idea-canvas-plan.md](./idea-canvas-plan.md)（C01–C04 首版）。
> 分支 `feat/idea-canvas`；迁移 085–087；本文记录用法、A01–A17 验收结果与未验证事项。

## 使用说明

### 入口

- 桌面侧边栏「笔记」下方 **构思画布**（命令面板 `G C` 可直达；「快速新建 → 新建构思画布」一步建档）。
- `/canvas` 文档列表：新建 / 重命名 / 创建副本 / 删除（进垃圾箱，可恢复）。
- `/canvas/[id]` 无限画布工作区。

### 基本操作

| 操作 | 方式 |
| --- | --- |
| 新建版面 | 双击画布空白处（版面出现在指针世界坐标，标题立即聚焦）；或左上工具条「新建版面」 |
| 输入 | 单击选中、双击进入编辑；`Enter` 在当前**整个分区**下方新增通栏；`Shift+Enter` 模块内换行；中文输入法候选确认（isComposing）不会误建块 |
| 左右加号 | 悬停模块时出现在所属列左右边缘，点击给当前分区加一列（所有列重新分配宽度，版面总宽不变）；放不下最小列宽（120）时禁用并提示加宽版面 |
| 模块底部加号 | 仅在本列、当前块下方插入新块（与通栏是不同按钮、不同预览） |
| 添加通栏 | 分区右下「横条 +」按钮，效果与 Enter 相同 |
| 调整列宽 | 拖动列间分隔线（整次拖动一个撤销事务；之后该分区为手动比例，可属性栏恢复「等分 / 智能比例」） |
| 版面移动 / 改宽 | 悬停版面顶部操作条拖动移动；右缘拖动改宽（智能比例分区随后自动重算） |
| 图片 | 图片模块占位点击选择文件（≤5MB）；「完整显示 / 铺满裁切」切换；一文一图两列默认智能比例（25%–60% 夹逼），插入图片 / 改版面宽 / 文本编辑结束后重算 |
| 自由容器 | 工具条「自由文本 / 自由图片」；拖动移动、右下角改宽、属性栏调层级；`Enter` 只换行；选中显示「自由定位」徽标，不参与自动排版 |
| 样式 | 右侧属性栏：角色（标题/正文）、字号档、加粗、文字色、对齐、背景、圆角；版面：宽度/背景/圆角 |
| 缩放 / 平移 | Ctrl/⌘+滚轮围绕指针缩放（10%–400%）；滚轮/触控板平移；空格或中键拖拽平移；右下角 −/+/100%/适合全部 |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z`（含文本输入，连续输入合并为一个事务；IME 一次提交一个事务） |
| 预览 | 顶栏眼睛图标或 `Esc` 退出；隐藏全部编辑控件 |
| 保存 | 停止编辑约 800ms 自动保存（串行 + revision CAS）；状态显示「保存中 / 已保存 / 仅保存在本机 / 保存失败 / 存在冲突」；mock 下显示「已保存（演示模式，仅本机）」 |
| 冲突 | 保存被拒（他人/他标签页已更新）时暂停自动写回，提供「查看云端版本 / 将本地内容另存为副本 / 暂不处理」 |
| 删除 / 恢复 | 版面操作条删除版面、属性栏删块/容器；文档删除进垃圾箱，可恢复、可彻底删除 |

### 手机端

从侧栏抽屉进入；列表为标准页面；详情**只读预览**（返回、缩放可用），顶部提示编辑请在桌面进行；底栏仍为五个入口，不新增。

### 数据与备份

- 独立 `canvas_documents` 表（`content` 为 Board→Section→Column→Block 结构 JSON，`schemaVersion=1` + `revision` 并发修订）。
- 全局设置页备份导出/恢复自动包含画布（格式 v6，兼容导入 v2–v5 旧备份）；附件打包/恢复会收集并重绑画布内的 `/storage/` 图片引用。
- mock 模式：文档存内存（刷新即失），草稿与本机图片存 IndexedDB（按账号隔离）；上传走本机适配器（`mock-image:` 引用，刷新后由草稿/本机重建预览）。

## 验收结果（A01–A17）

图例：✅ 自动化验证；🟡 部分（列出缺口）；⛔ 未验证。测试命令：
`pnpm --filter @organize/web typecheck`、`pnpm --filter @organize/web test`（179 文件 / 1344 用例通过）、
`pnpm --filter @organize/web e2e -- e2e/canvas.spec.ts e2e/visual-canvas.spec.ts`（10 项通过，Playwright + mock）。

| --- | --- | --- |
| A01 多缩放双击坐标 | ✅ | E2E：100% 与连续放大至 207% 后双击，版面 left/top = (屏幕−pan)/zoom，初始宽 640，标题聚焦可输入 |

| A04 左列加块等高/右列跨层 | ✅ | E2E（渲染矩形）：左两块等高，右单块高=左两块+间距 |
| A05 右列加块/删除恢复 | ✅ | 单测：两列两块总高一致；删除左下后左列单块拉满、空列回收、版面永不为空 |
| A06 IME/Shift+Enter/选区/粘贴 | 🟡 | IME：合成事件（keyCode 229/isComposing）Enter 不建块、compositionend 后建块（E2E）；选区/光标中间拆分不丢字（单测）。缺口：真实硬件输入法手感、多行粘贴为 textarea 原生行为未显式断言 |
| A07 一文一图智能比例 | 🟡 | 单测：智能权重 25%–60% 夹逼、图片高=内宽/比例、contain/cover 命令、编辑期宽度稳定。缺口：浏览器真实图片上传→重排全链未自动化（上传编排与 IndexedDB 适配器有单测） |

| A09 撤销重做原子性 | ✅ | E2E：连续 Enter 后两次 ⌘Z 逐级回退；单测：内容+ID+焦点原子恢复、重做栈清理；上传回调不复活（资产由文档驱动） |
| A10 自由容器独立坐标 | 🟡 | 单测：创建/移动/改宽/层级/删除，Enter 只换行；版面增长不推挤（坐标独立存储）。缺口：浏览器拖拽全链未自动化 |
| A11 自动保存/断网/刷新/账号 | 🟡 | 单测：800ms 防抖合并、串行补发、冲突暂停、断网重试、旧响应不覆盖、not-found 不复活；草稿按账号隔离（单测）；恢复链路 E2E（注入草稿→404→另存副本→内容完整）。缺口：真实弱网/真实双账号浏览器环境 |

| A14 备份往返 | 🟡 | 备份合同单测全绿（v6 新表、v2–v5 兼容补空、附件扫描/重绑含 canvas content、恢复链 revision 复位）；mock 恢复 handler 同构。缺口：真实导出→恢复含画布图片的端到端浏览器流 |
| A15 mock 主流程 + 刷新 | ✅ | E2E：交互演示、保存状态明确标注「演示模式，仅本机」、远端缺失时草稿另存为新画布内容完整 |
| A16 主题/侧栏/手机 | ✅ | 明暗主题截图（docs/idea-canvas-screenshot-*.png）、坐标换算基于视口实测不依赖侧栏宽度、手机只读 E2E（隐藏底栏、只读提示、无通用创建按钮）；收起侧栏走 CSS 变量偏移未显式走查 |
| A17 仅键盘 | 🟡 | 块 `role=button` + Enter 进入编辑、Delete 删块、方向键移动/加宽版面、⌘Z/⇧⌘Z、加号可聚焦按钮带 aria-label。缺口：完整仅键盘走查（读屏标签全量核对） |

## 未验证事项（环境限制，需真实环境补验）

1. **数据库层完全未在真实 Supabase 验证**（本机无 Docker）：迁移 085（表/RLS/GRANT/触发器/`canvas_document_patch` CAS RPC）、086（垃圾箱 RPC 接入）、087（备份恢复链）均按既有迁移模式（055/073/060/075）编写且 mock 对齐契约，但 RLS 用户隔离、CAS 原子性、RPC 权限口径需 `supabase start && supabase migration up` 后补验（A12/A13 的真实后端部分）。
2. 真实硬件中文输入法（搜狗/系统 IME）的 Enter 手感与候选确认（A06）。
3. 真实图片上传（/api/upload → images bucket）后的智能比例重排全链（A07）与备份附件往返（A14）。
4. 真实双标签/双账号并发冲突（A12）与迟到保存竞争（A13）。
5. 性能目标（5 版面 200 模块 P95<100ms）未做基准测量；当前实现为全量重渲染 + 测量缓存，未做虚拟化。

## 已知边界（规格内的首版裁剪）

- 任意块内的递归横向嵌套、块拖拽排序、跨版面拖放、自由容器↔自动模块互转：后续版本。
- PNG/PDF 导出、PPTX、AI、实时协作、模板市场：规格明确后置，界面无占位按钮。
