# 稍后读智能物料整理

在「稍后读」顶部的「导入物料」区域拖入文件，或点「选择文件」。文件选定后立即识别，完成后生成一篇未读条目。多份物料一起整理，正文标明来源文件名；内容类型和主题词自动保存为阅读标签，可通过现有标签筛选查看。结果进入阅读库，不会创建笔记或修改笔记编辑器。

「选项 / 粘贴文字」提供两种模式及文字/截图粘贴：

- **按内容整理并分类**（默认）：按主题归纳、识别资料类型，生成标题、小节、要点、表格和资料中明确的待办。
- **提取并排版**：要求模型完整转录可辨认文字并恢复顺序、层级和表格，不进行摘要；无法辨认的部分标记 `[无法辨认]`。

## 配置和使用范围

在「插件」启用内置 **智能物料整理**，然后在「设置 → AI 服务」填写 OpenAI 兼容地址、密钥和模型。图片要求文本/视觉模型支持 Chat Completions 的 `image_url` 输入；录音还需要转写模型。复用既有配置，无新增数据库迁移。

支持 PNG/JPEG/WebP/GIF；UTF-8 TXT/Markdown/CSV/JSON；MP3/WAV/M4A/OGG/WebM 音频。PDF、Office 文档和视频需先转成图片或文本。

每批最多 6 个文件、合计 20MB，单图 8MB，纯文本文件 200KB；文字及录音转写合计 4 万字符。超过上限明确拒绝，不静默截断。每用户每分钟 5 次，复用共享限流模块。

原文件只用于此次识别，不自动上传保存；阅读库保存识别后的正文和来源文件名。识别由用户配置的服务商执行，演示模式不会伪造结果。模型输出可能有误，应对照原件核对。

## 保存与失败语义

所有条目仍经过 `collectReadingItem` 唯一入口，新增带 `kind: material` 的类型分支：验证整理结果 → 验证账户 → 按账户及物料指纹查询活跃重复项 → 固定 8 字段保存为未读 → 添加主题/分类标签 → 通知列表刷新。既有 URL 抓取和失败仅存链接语义不变。

物料指纹由文件内容、文件名、粘贴文字和模式生成 SHA-256，URL 列保存为 `urn:organize:material:<指纹>`。这是标识符，不是网页链接；阅读卡片、阅读页、公开分享均隐藏打开原文，来源显示「导入物料」。右键新标签页打开和转为笔记时使用内部阅读链接。URN 作为普通字符串兼容现有备份/恢复。

保存失败会保留已识别结果，可「重试保存」而不重新调用模型；标签部分失败时明确提示，重试只补标签，不重复创建正文。软删除后再次导入可以创建新条目。与原 URL 收集相同，跨标签页的并发去重仍非原子，不承诺数据库级唯一性。

处理中重复投放会被拦截。取消或离开页面后不发起保存；保存已开始时不提供取消按钮，已发出的数据库写入可能在离开页面后完成。保存时校验预期账户，避免处理中切换账户后写错归属。取消不保证撤销服务商已开始的计算。

## 插件扩展和安全

SDK 提供 `material-processor` 扩展与可选 `PluginDataAccess.organizeMaterials` 能力；多个启用的处理器可在入口选择。插件通过宿主调用模型，不读取密钥。

`POST /api/ai/materials` 校验会话、真实请求字节上限、文件类型和图片签名。AI 出网复用 `safeAIRequest` 的 SSRF 校验、连接钉扎、重定向检查及密钥脱敏。模型返回白名单结构，经验证和 HTML 转义后构建阅读正文，不执行模型生成的 HTML。
