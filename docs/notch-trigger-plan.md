# 刘海激发器（Notch Trigger）方案 —— 定稿 v2（2026-09-01 原型讨论拍板）

> 状态: **已实现（v1）**。实现落点：Rust 侧 `desktop/src-tauri/src/notch.rs`
> （两窗口 + hover 状态机 + ⌘⇧M + 窗口层级/刘海检测），web 侧
> `apps/web/app/desktop/notch/` 与 `apps/web/components/desktop/notch/`
> （胶囊/面板/演示态），纯逻辑与白名单在 `apps/web/lib/desktop/notch.ts`。
> 下文保留原始方案内容（决策依据与默认值仍然有效）。
> 前置: 依赖 ADR 0004 的托盘常驻基建（已落地，master = 039910c）。

## 1. 目标

在 MacBook 顶部刘海位置放一个常驻「激发器」胶囊：鼠标移上去弹出**速记
面板**（Enter 保存进应用），面板同时提供今日待办、最近速记与其他功能的
快速入口。把「打开应用 → 找到速记页 → 输入」压缩成「随手一碰 → 输入 →
Enter」。

## 2. 形态

主形态 = 刘海延伸胶囊（纯黑，与刘海融为一体）；全局快捷键 ⌘⇧M 为兜底，
唤出同一个面板。不做菜单栏 NSStatusItem 形态（B 案已否）。

## 3. 用户拍板的核心决策（2026-09-01）

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 展开交互 | **hover 停留 150ms 自动展开**，零点击；快速划过不触发；失焦 / Esc / 保存成功自动收起 |
| 2 | 胶囊观感 | **纯黑胶囊 + 极淡 ⚡ 图标**：平时 15% 透明度（≈隐形），hover 升到 40% 并微加宽 |
| 3 | 面板内容 | **速记输入 + 最近 3 条速记 + 今日待办 + 快速入口**（选项 1 和 3 全要） |
| 4 | 快捷键兜底 | **⌘⇧M**（M = Memo；⌘⇧S 已被快速保存占用，⌥Space 与启动器冲突大） |

## 4. 面板布局（380×520）

```
┌────────────────────┐
│ #标签 输入区        │  ← 大 textarea，Enter 保存
│ （约 120px）        │     Shift+Enter 换行（对齐 /memos 习惯）
├────────────────────┤
│ 今日待办（约 120px）│  ← 今日到期任务 ≤3 条，可勾选完成
│ ☐ 写周报            │     空态：「今天没有待办 ✨」
│ ☐ 回复 K            │
├────────────────────┤
│ 最近速记（约 150px）│  ← 最近 3 条（含 #标签 高亮），保存后
│ · #想法 刚才        │     立即出现在顶部（本地乐观插入）
│ · #会议 10:24       │
├────────────────────┤
│ ⚡速记 📚稍后读 📝笔记 │  ← 快速入口：主窗口跳转后收起面板
│ ✅待办 ⚙设置         │     ⚡速记 = 打开主窗口 /memos
└────────────────────┘
```

## 5. 默认值（用户未特别表态，按惯例定，可推翻）

1. **动画**：面板淡入 + 下滑 8px，180ms ease-out；收起 120ms。
2. **误触阈值**：hover 停留 ≥150ms 才展开；胶囊 hover 本身只做透明度
   变化，不弹任何东西。
3. **尺寸**：胶囊约 180×28（覆盖刘海两侧延伸），面板 380×520。
4. **无刘海 Mac / 外接屏**：用 `NSScreen.safeAreaInsets.top > 0` 检测；
   无刘海时胶囊悬浮在顶部居中（观感略突兀），设置页提供「隐藏激发器」
   开关（只留 ⌘⇧M）。
5. **多屏**：只跟主显示器（刘海只存在于内建屏）。
6. **全屏应用**：全屏 space 会盖住胶囊（系统限制），接受现状，⌘⇧M 兜底。
7. **未登录态**：面板显示「登录后可用」+ 去登录按钮（打开主窗口到
   /login）；登录 cookie 各窗口共享（同 WKWebsiteDataStore），登录一次
   面板即用。
8. **保存失败**（离线/未登录）：输入内容保留在 textarea 不清空，红字
   提示；不做离线队列（v1 后再看，与 web 端 memos 行为对齐即可）。

## 6. 技术实现要点（Tauri v2 / macOS）

- **两个 Rust 窗口**：`notch-trigger`（transparent + decorations false +
  alwaysOnTop + skipTaskbar + visibleOnAllWorkspaces，180×28）与
  `notch-panel`（380×520，默认隐藏）。`primary_monitor()` 顶部水平居中
  定位，监听显示器变更重算。
- **hover 状态机**：trigger 窗口 web 侧 `mouseenter` → invoke Rust
  `expand_panel`（内部做 150ms 判定，防抖）；panel `blur` → Rust
  `collapse`。均为自有窗口，不需要辅助功能权限。
- **数据链路（零新后端）**：
  - 保存：`POST /api/memos { content }`（服务端 `parseMemoTags` 解析
    #标签），同 `/memos` 页一致；mock 模式走既有 api-shim。
  - 最近速记：`GET /api/memos?limit=3`（打开时拉一次 + 保存后乐观插入）。
  - 今日待办：复用 tasks 域现有客户端查询（due 今日 + 未完成 ≤3），
    勾选走既有更新链路。
  - 快速入口 / 设置 / 去登录：emit `navigate`（复用 `NavigateBridge` 与
    `sanitizeNavigatePath` 白名单）→ 主窗口路由跳转。
- **快捷键**：⌘⇧M 经既有 global-shortcut 插件注册，toggle panel；
  与托盘「打开速记」归一（托盘项改为打开主窗口 /memos，语义不变）。
- **加载方式**：两窗口均加载同 origin 的专用轻页面（web 内新增
  `/desktop/notch` 路由，桌面壳限定；普通浏览器可访问但无窗口管理，
  仅渲染演示态）。判定走 `getPlatform() === "tauri"`。

## 7. v1 原型范围与里程碑

1. **M1 壳与胶囊**（半天）：trigger/panel 窗口 + 定位 + hover 展开/收起
   状态机 + 纯黑胶囊 ⚡ 样式。
2. **M2 速记链路**（半天）：面板 textarea → 保存 → toast → 收起 →
   最近速记列表回显。
3. **M3 待办与入口**（半天）：今日待办区（含勾选）+ 快速入口 + 设置开关
   （隐藏激发器）+ ⌘⇧M。
4. **M4 打磨**（半天）：动画时序、误触调参、无刘海检测、未登录态、
   异常路径（断网保存失败）。

## 8. 验收标准

- [ ] 刘海 MacBook：胶囊贴合刘海，hover 停留 150ms 展开，Esc / 失焦 /
      保存成功收起；快速划过不弹。
- [ ] 面板 Enter → 速记入库（#标签解析），出现在最近速记顶部，/memos 可见。
- [ ] 今日待办 ≤3 条可勾选，与 /tasks 数据一致。
- [ ] 快速入口点击 → 主窗口跳对应页；⚡速记入口 → /memos。
- [ ] ⌘⇧M 任意时刻唤出/收起同一面板。
- [ ] 未登录面板提示登录；断网保存失败时内容不丢。
- [ ] 普通浏览器 / PWA / 移动端零影响。
