# 移动端界面重构

2026-09-07；基线 `07b51d6`。本次用户要求整体重新梳理移动端，替代旧设计计划中“顶部抽屉 + 底部两颗悬浮按钮”的移动导航方案。桌面沿用当前布局。

## 已确认的问题

- iOS 模拟器中，固定顶栏的 56px 高度包含刘海安全区，挤压标题；正文仍只留 56px，造成重叠。
- 五个日常模块全藏在侧栏，每次切换都要打开抽屉。底部仅搜索和新建，不能说明当前所在模块。
- 稍后读重复显示页面名，同时堆采集、粘贴、批量导入、搜索、排序、状态筛选；首屏主要在展示工具。
- 文章详情把桌面动作平铺到小屏；笔记详情叠加全局顶栏和自己的工具行。
- 任务清单选择依赖全局侧栏；固定 `100vh` 减常量没有统一计入安全区、工作区标签和底栏。
- 多个输入提示仍描述桌面回车/快捷键；创建面板没有模态焦点管理，没有跟随可见视口避让键盘。

## 新的界面逻辑

| 层级 | 内容 | 行为 |
| --- | --- | --- |
| 一级模块 | 首页 / 阅读 / 笔记 / 待办 / 速记 | 底部固定五项，显示当前模块，记住各模块列表地址，以及 URL 中的阅读状态、标签和任务范围 |
| 全局工具 | 搜索 / 更多导航与设置 | 顶部 44px 触控入口；更多包含目录、清单、收藏、协作和设置 |
| 当前页动作 | 保存链接 / 新建笔记 / 添加待办 / 新建速记 | 顶部加号依据当前模块执行；创建复用既有服务和离线队列 |
| 模块内筛选 | 阅读状态、笔记排序、任务清单与工作区视图 | 紧邻列表，保留可读标签；任务与日历保留 scope/list |
| 详情 | 文章、笔记、任务内容 | 使用详情自己的顶栏；收起全局底栏；返回恢复来源列表 |
| 输入与弹层 | 快速创建、搜索、选择器 | 底部面板、明确取消/保存、16px 输入字号；可见视口跟随键盘 |

视觉继续使用现有暖白、炭灰和陶土橙，主内容靠文字与分隔组织。导航与操作固定，正文保持唯一阅读区域。没有真实数据时呈现可操作空态，不添加虚构统计。

## 验收范围

360 / 390 / 430px 手机、768px 平板和桌面回归；检查安全区、页面无横向溢出、主导航选中、模块切换、筛选后返回、创建与刷新、任务清单与日历、更多入口、搜索关闭、软键盘、笔记标签与文章工具。逻辑测试覆盖路由边界、任务工具/详情区分、来源地址校验和键盘判断。

## 实施验证（2026-09-08）

- `pnpm --filter @organize/web typecheck`、`lint`、生产 `build` 全部通过。
- 全量 Vitest：147 个测试文件、1095 条用例通过；其中新增移动路由/来源地址/键盘判断测试 15 条，任务工作区范围保留测试新增 2 条。
- 360px 阅读详情与 430px 阅读列表检查：页面宽度等于视口宽度，无横向溢出。390px 检查笔记列表、编辑器和待办；768px 验证切换到桌面侧栏布局且无横向溢出。
- 独立本地 Supabase 验收账号：笔记写入正文后刷新仍可读取；任务新增后列表即时更新；速记保存后刷新仍可读取。验收数据未写入原账号。
- 实际点击验证：阅读状态筛选 → 文章详情 → 返回保留状态；任务清单 → 日历 → 任务保留 `scope/list`；更多、文章操作、全局搜索与批量导入可打开和关闭。
- iOS 26.5 模拟器：顶部刘海区与底部导航正常；系统软件键盘弹出时，新建速记面板抬升，输入、保存、关闭均可见；关闭后恢复主导航。曾出现旧页面缩放导致裁切，双击恢复正常缩放后确认布局正常。
- 本地最终预览使用生产构建，地址 `http://localhost:3000`。源码位于 `codex/mobile-navigation-redesign`，未推送或合并。

## 验证边界

尚未覆盖 Android 实机、系统分享扩展和外部抓取/AI服务；浏览器与 iOS 模拟器检查不能替代真实设备的全量验收。列表记忆保存的是模块地址与 URL 筛选，笔记列表的临时搜索/排序以及页面滚动位置仍沿用原页面行为，不承诺跨页面恢复。
