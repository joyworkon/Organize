# 术语表（UI 用词规范）

> 2026-10-11 设立。UI 文案、空状态、toast、快捷键说明、命令面板都按本表用词；
> 代码标识符（表名、路由、类型名）不受约束，保持现状。新增界面文案前先查本表。

| 概念 | UI 统一用词 | 不再使用 | 说明 |
| --- | --- | --- | --- |
| 产品名 | **Cairn** | Organize | Organize 只是仓库 / 包名（`@organize/*`），界面、引导、登录页一律 Cairn |
| 首页 | **工作台** | 首页、仪表盘 | 侧栏第一项；登录 / 注册 / 重置密码成功后都回到工作台 |
| 文章 + 导入文件 + 速记的总入口 | **资料库** | 收件箱 | 「全部」主列表只放阅读物；速记收在顶部「最近速记」条 |
| 待读的网页 / 文章 | **稍后读** | 收件箱、阅读列表 | 状态只有三态：**未读 / 在读 / 已读** |
| 随手记下的短文字 | **速记** | 闪念、memo | |
| 富文本长文档 | **笔记** | 文档、页面（仅「子页面」保留「页面」） | |
| 基于某篇文章写的笔记 | **读书笔记** | — | 阅读页底栏主按钮「写读书笔记 / 打开读书笔记」，标题「读《…》的笔记」 |
| 把正文整篇复制进笔记 | **全文转为笔记** | 转为笔记 | 与「读书笔记」区分：前者复制正文，后者只放链接 + 摘录 + 我的想法 |
| 模块：要做的事 | **待办** | — | 侧栏、快速记录类型 |
| 待办中的单条 | **任务** | — | 「全部任务」「完成任务：xxx」 |
| 用户写的反思 / 总结（lessons 表） | **复盘** | 经验、经验总结 | 模块与列表名统一为「复盘」，类型细分为 **任务复盘 / 经验教训 / 灵感** |
| 按日期回看活动记录 | **回顾**（日历回顾） | 复盘 | 系统生成的活动时间线，不是用户写的内容 |
| 删除后的暂存处 | **垃圾箱** | 回收站 | |
| 自由排版的白板 | **构思画布** | 白板 | |

## 快速记录（统一入口）

工作台输入框与右下角「＋」面板共用 `lib/capture/detect.ts`：

- 含链接 → 稍后读
- 以「待办：」「任务：」「todo:」「[ ]」开头 → 待办（前缀自动去掉）
- 其余 → 速记

输入时实时提示「回车保存为「X」」；「其它类型…」把已输入内容带进「＋」面板改选类型。
