# 工作台逐功能检查

日期：2026-10-16。基线：PR #342 / `9d3ea7f`。本轮检查正式工作台的今天、日历回顾、趋势统计和快速记录，沿用既定中性灰 UI；不重做画布或其它模块。

交付：[PR #343](https://github.com/joyworkon/Organize/pull/343)。完整 CI 结果以该 PR 最新提交的5项门禁为准，全部通过才合并。

## 已复现并修补

| 问题 | 触发与修复 |
|---|---|
| 切换账号仍显示旧账号主体 | A 标签页保持打开，收到 B 登录事件后，快速记录已换账号，主体却仍显示 A 的缓存。Hub 现在统一确认身份，账号变化重建三视图、搜索和输入；登出卸载私有主体，B 读取失败不会回落 A 内容，旧 A 慢请求不能回填 B。 |
| 今天的全天任务误报过期 | 全天日期按本地零点存储，旧文案中午直接比较后报“已过期”。现在复用 `effectiveDueDate` 合同并显示“今天到期”，定时任务仍按具体时间显示。 |
| 今天的任务行缺少键盘入口 | 原来只有 div 的鼠标点击；改成独立详情链接，与完成按钮并列，避免嵌套交互。手机完成按钮真实 44×44px，状态内圈仍为16px，桌面32px。 |
| 回顾任务无法打开详情 | 完成任务现在直接链接到 `scope=completed&task=<id>`，保留完成时间与分类。 |
| 手机回顾日期控件未同步规范 | 输入框从32px/14px改成44px/16px；日期一行、前一天/回到今天/后一天一行，320px不出现单个箭头被挤到下一行。桌面保持32px/14px。 |

账号边界只隔离工作台的客户端状态；没有修改 Supabase Auth、RLS、数据库、保存或提醒协议。同账号的 TOKEN_REFRESHED / SIGNED_IN 保留同一个输入实例、搜索和草稿。按账号落盘的草稿保持原键；存储不可用时仍遵守原有提示，不承诺保全未落盘内容。
