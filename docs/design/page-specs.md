# 页面规格与路由合同

本表基于2026-10-15源码制定，正式接入范围与验证边界见[接入记录](adoption-report.md)。六类静态预览用于表达设计，正式组件仍按本表逐项验收。所有页面继承根DESIGN.md的对比、键盘、触屏与状态要求。`D`=≥768桌面壳；`M`=≤767手机；≥1200只用于辅面并排。主动作是当前任务最重要的一项；已进入编辑流程时自动保存取代“新建”。未列出的query参数必须原样保留。

|---|---|---|---|
| 工作台今天 `/` `/?view=today` | 快速记录提交 | D紧凑问候+单composer，下方今天待办与继续阅读两列，最近资料纵向行；M同序单列，不挤正文 | 首次使用保留composer和一条入门指引；查询加载分区独立，不能一个失败全屏清空；今日无任务给查看全部。页内搜索仅搜今天可见对象。 |
| 工作台回顾 `/?view=review` | 选择日期查看记录 | D月历+当天时间线，M周条/日期picker+时间线 | 无活动日明确显示；日期、类型筛选反映到状态；`/review`继续跳转。 |
| 工作台统计 `/?view=stats` | 切时间范围 | D数值横条+一主趋势图+分类表，M数值换行、图不裁轴标签 | 无数据不画假趋势；图提供数表与文字摘要；`/stats`继续跳转。 |

| 资料库集合 `/library?view=collections` | 新建集合 | D集合行+内容摘要，M单列；进入`&collection=<id>`后显示集合头+资料列表 | 空集合添加资料、成员源失效、整理生成中/失败；删除集合确认是否仅解组。集合详情保持同URL参数，返回保留筛选。 |
| 阅读详情 `/library/[id]` | 继续阅读/在更多中整理 | D44px详情头+760px正文，目录/高亮侧面；M正文全宽、辅面sheet | 阅读进度与status沿用真实滚动合同；抓取失败仅链接、无正文、重抓失败保留已有正文。原文入口始终可达；字体/全宽偏好不重置；高亮引用失效有源状态提示。 |
| 阅读整理稿（同`/library/[id]`内部模式） | 保存整理稿 | D正文/整理稿局部切换，M全宽单稿 | 原文与派生稿明确区分；生成进度/取消/无AI配置/失败重试；编辑器仍用digest-editor，不虚构新路由、不可把“生成完成”当已保存。 |
| 笔记列表 `/notes` | 新建笔记 | D分组条+筛选排序/视图/多选+行，M分组可滚、工具合并 | 分组/未分组/卡片视图/导入/自动归组/图谱入口保留；默认列表不显示空标签条。标题搜索及tags过滤，批量删除可撤销。 |

| 笔记历史（编辑器内history panel/dialog） | 预览/恢复选定版本 | D右侧版本列表+正文预览，M全屏面板 | 当前未保存稿先保全；恢复确认、失败仍保留预览；只读角色按能力隐藏恢复，不把版本预览当普通可编辑正文。 |
| 笔记评论/建议（编辑器内panel） | 发送评论/接受建议 | D侧面，M sheet；锚点回跳不改变正文坐标系 | 未登录/无评论权限、已解决、原块删除、加载失败；接受建议沿用实际权限与写路径，按下回车IME期间不发送。 |

## 预览验收入口

离线打开`preview/index.html`。外侧说明栏声明“设计预览 · 演示资料仅存此浏览器”；内部产品文案不出现token/模拟后端/测试术语。可切换六类主页面、资料五视图、阅读钻入及无正文状态、笔记列表/编辑、任务详情。主题/手机宽度/状态选项在外层，避免冒充正式产品设置。手机宽度可检验drawer、阅读宽度、编辑宽度；真实软键盘与安全区仍须真机验收。
